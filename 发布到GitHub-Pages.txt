发布到 GitHub Pages —— 你只需要点一下

仓库地址我已经写进脚本了：https://github.com/dioda91/sudoku-mansion.git
本地这个文件夹已经是一个完整的 git 仓库（main 分支，101 个文件，已提交），
还额外建了一个内容相同的 gh-pages 分支（GitHub 有时会用它自动开 Pages）。

=====================================================
第一步：双击 一键推送到GitHub.bat
=====================================================

窗口里会显示目标仓库，按任意键开始。
中间可能弹出 GitHub 登录窗口，登录一次即可（这台机器的 git 走你配的代理
127.0.0.1:7897，跑之前确认 Clash 开着）。

它会推两个分支：main 和 gh-pages。
注意：仓库里那份自动生成的 README 会被我准备的 README 覆盖——本来就是这个包的说明，
所以不会有损失。

=====================================================
第二步：开启 Pages（30 秒）
=====================================================

1. 打开 https://github.com/dioda91/sudoku-mansion/settings/pages
2. Source 选  Deploy from a branch
3. Branch 选  main  ，目录选  / (root)  ，点 Save
4. 等 1~2 分钟

你的网址就是：https://dioda91.github.io/sudoku-mansion/

如果打开就是 404，多半是第 4 步还没跑完，再等两分钟刷新。

=====================================================
手机上怎么玩
=====================================================

1. 手机浏览器打开 https://dioda91.github.io/sudoku-mansion/
2. 横屏，菜单里选「添加到主屏幕」，以后从桌面图标进
3. 因为是 https，Service Worker 生效：打开过一次之后断网也能玩，
   电脑关机、不在家、外面用流量都不影响。
4. 存档在手机浏览器里，换手机或清缓存前用同目录的 存档备份.html 导出。

=====================================================
如果你不想自己点：另一条路（把令牌给我，我推）
=====================================================

我这边所在的运行环境没法直接连 GitHub 推送（Windows 加密凭据库被隔离，git 连
内部管道都建不起来），也没有可用的令牌，所以默认让你点一下。
你如果愿意，可以到下面这个页面创建一个只对这一个仓库有写权限的令牌：

  https://github.com/settings/personal-access-tokens/new
  Repository access 选 Only select repositories → sudoku-mansion
  Permissions → Repository permissions → Contents 选 Read and write
  生成后把令牌发我，我用 API 直接把 101 个文件推上去，不用你碰命令行。
  推完你可以立刻在同一个页面把它 Revoke（撤销），令牌就作废了。

=====================================================
出问题看这里
=====================================================

推送报错 authentication / 403：Clash 没开，或登录窗口被关掉了。重开脚本再试。
推送报错 rejected：脚本用的是 --force，理论上不会出现；真出现就把报错发我。
Pages 打开是仓库首页：说明 Pages 还没开启，去上面第二步设置一下。
页面白屏：确认仓库首页能看到 index.html（不是套在子文件夹里）。
没有声音：正常，音乐 136MB 没上传，本地想要声音就跑 补上音乐.bat。
